# 🚖 Mega City Cab Booking System

## Overview
The **Mega City Cab Booking System** is a Java web application developed using **Java, JSP, Servlets, and MySQL**. It allows three types of users: **Customers, Drivers, and Admins** to manage and book cabs efficiently.

---

## Features

### 🧑‍💼 Customer:
- 📝 Register and login
- 🚖 Book a cab
- ❌ Cancel bookings
- 📜 View booking history

### 🚖 Driver:
- 📝 Register and login
- ✅ Accept bookings
- ❌ Cancel bookings
- 📜 View assigned bookings

### 🛠️ Admin:
- 📌 Manage bookings (view, edit, delete)
- 🚗 Manage vehicles (add, edit, delete)
- 🧑‍💼 Manage drivers (add, edit, delete)

---

## 📊 Pricing Calculation
The booking price is calculated based on:
- 📏 Distance (km)
- 🚘 Vehicle type
